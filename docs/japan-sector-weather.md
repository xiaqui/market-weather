# 日本国内天気図 構想

## 位置づけ

既存の金融天気図を「世界天気予報」とみなし、その国内版として日本株の業種・セクターを日本地図上の地域に見立てて表示する構想。

世界天気予報では、日経平均 / NYダウ / USDJPY / GOLDの相互配置から、世界的な資金の流れやリスク選好を読む。

日本国内天気図では、同じ考え方を日本株の業種間へ縮小し、

- 製造
- 金融
- 化学
- 商社
- 半導体
- 自動車
- 不動産
- 小売
- 医薬品
- 電力・ガス
- 通信
- 運輸
- 建設

などの業種・セクターを「地方」に見立て、それぞれの天気と次営業日の予報を出す。

## 1. 世界天気図との対応

概念上は次の二層構造。

```text
世界天気予報
= 世界の主要市場どうしの配置
= 日経 / Dow / USDJPY / GOLD

日本国内天気予報
= 日本株の業種どうしの配置
= 製造 / 金融 / 化学 / 商社 / 半導体 / 自動車 ...
```

世界天気図が「海外から日本へどんな気圧配置が来ているか」を見るものなら、国内天気図は「日本市場の中でどの地域・業種に晴れや雨が分布しているか」を見るもの。

## 2. 業種を地方に見立てる

実在の地理と産業立地を厳密に対応させる必要はない。

UI上の直感性を優先し、各業種を日本地図上のエリアとして固定配置する。

例:

- 北海道・東北: 資源 / 電力 / 素材
- 関東: 金融 / 不動産 / 通信 / 小売
- 中部: 自動車 / 機械 / 製造
- 関西: 化学 / 医薬 / 電機
- 中国・四国: 素材 / 造船 / 化学
- 九州: 半導体 / 電子部品 / エネルギー

これは統計上の正式な地域分類ではなく、金融天気UIとしての概念マップ。

必要なら将来、実際の企業本社・生産拠点分布を参照して配置を洗練する。

## 3. 各地方 = 各セクターの個別予報

各セクターについて次営業日の方向予報を持つ。

例:

```text
中部 / 自動車
晴れ
上昇確率 63%

関東 / 金融
曇り
上昇確率 51%

関西 / 化学
雨
上昇確率 42%
```

天気マークは既存と同じく方向感、別軸でボラティリティやリスクを表示する。

## 4. セクター版Analog

単に各業種を独立予測するのではなく、業種間の相対配置を1枚の国内天気図として扱う。

例:

```text
自動車 ↑
銀行 ↓
半導体 ↑
化学 →
商社 ↑
不動産 ↓
```

この「業種の配置」が過去のどの局面に似ていたかを探し、その後の各セクターの動きを予測する。

世界版と同じく、

- 絶対値より相対的な強弱
- 複数セクターの同時配置
- 過去類似局面
- 次営業日の個別結果

を使う。

## 5. 世界→日本国内の階層モデル

将来的には二段構えにできる。

```text
世界天気図
↓
日本全体への外圧
↓
日本国内天気図
↓
セクター別予報
```

例えば、

- 米株上昇
- 円安
- GOLD弱含み

という世界天気が来ている時に、日本国内では

- 自動車に追い風
- 銀行は中立
- 輸入コスト敏感業種に逆風

のように影響が分かれる可能性がある。

世界天気と国内天気をつなげることで、「日経が上がるか」だけでなく「どの業種がその上昇を担うか」まで見える。

## 6. 個別株への拡張

国内天気図のさらに下層として、セクター内の個別株へ落とすこともできる。

```text
世界
↓
日本
↓
業種
↓
個別株
```

ただし個別株は決算・材料・需給・企業固有ニュースの影響が大きくなるため、最初から個別株まで広げない。

まずはセクターETF・業種指数・TOPIX-17 / 東証33業種等の集約単位を候補とする。

## 7. 地図UI

日本地図を天気図のように見せる。

例:

- 中部: 自動車 晴れ
- 九州: 半導体 晴れ時々曇り
- 関東: 金融 雨
- 関西: 化学 曇り

タップすると、

- 上昇確率
- Trend
- Analog
- Ensemble
- 予想レンジ
- ボラティリティ
- 注意報 / 警報

を表示する。

## 8. 国内版の注意報・警報

世界版の金融気象警報を国内セクターにも適用できる。

候補:

- 半導体高温注意報
- 銀行株急落注意報
- 自動車円安追い風注意報
- 不動産金利上昇注意報
- 内需全面雨注意報
- 製造業広域晴天
- セクター分断注意報

名称は遊び心を残しつつ、実際の予測指標と対応させる。

## 9. データ候補

最初は構成銘柄を直接集計するより、業種指数やETFが使えるならそちらを優先する。

候補:

- 東証33業種指数
- TOPIX-17
- セクターETF
- 各業種代表銘柄バスケット

Yahoo Finance等で安定取得できるかを先に確認する。

## 10. なぜ日経から掘るのか

金融天気図フェーズ2では、日経平均だけがValidation 4期間すべてで、

- Trend
- always-up / always-down
- constant 50%
- expanding historical up-rate

を安定して上回った。

そのため次の研究方向として、日経を1つの市場として見るだけでなく、日本市場内部の業種配置へ分解する価値がある。

これは「日経が強かったからすぐ本番実装する」という意味ではなく、次の検証対象として優先順位が高いという意味。

## 11. 初期研究フェーズ案

最初から全33業種でやらない。

まず6〜10セクター程度に粗くまとめて検証する。

例:

1. 自動車・機械
2. 半導体・電機
3. 金融
4. 化学・素材
5. 商社・資源
6. 不動産・建設
7. 小売・内需
8. 医薬・ヘルスケア

この粗い国内天気図で、

- セクター間相対強弱
- 世界天気図からの外圧
- 翌営業日の方向
- Analog再現性

を先に検証する。

## 12. 実装時の原則

- 世界天気図と同じく未来リークを防ぐ
- 最初は業種数を絞る
- UIの地域配置と統計モデルの業種分類を混同しない
- 日本地図上の位置は表示上の比喩であると明確にする
- セクターごとのnaive baselineを必ず比較する
- 過去成績を見てから都合よく業種を選ばない
- prospective validationへつなげる
- 個別株は後段にする

## 13. 構想の核

世界天気図が「世界の資金の流れ」を天気として見るものなら、日本国内天気図は「日本市場内部の業種ごとの気圧配置」を見るもの。

最終的には、

```text
世界は晴れ
日本は曇り
中部の自動車は晴れ
関東の金融は雨
九州の半導体は晴れ時々曇り
```

のように、同じ金融市場を階層的な天気予報として読むUIを目指す。
