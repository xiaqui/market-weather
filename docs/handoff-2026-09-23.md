## 3. Android現在値取得

visible WebViewは本番GitHub Pagesを表示する。

Yahoo現在値取得は別のhidden WebViewで行う。

- local asset: android/app/src/main/assets/yahoo_fetch.html
- file originからYahoo Chart APIへplain fetch()
- WebView側だけuniversal file accessを許可
- JavaScriptInterfaceで結果をMainActivityへ返す
- 1市場ごとに1.5秒間隔
- 各fetch 10秒timeout
- HTTP 429発生時はそのcycleを止め、5分cooldown
- 成功した市場だけ更新
- 最後に成功した現在値はSharedPreferencesへ保存

取得タイミングは、起動 / 本当のフォアグラウンド復帰 / 下スワイプ手動更新。60秒pollは削除済み。

画面回転によるActivity再生成では savedInstanceState を使って直後の再fetchを抑止する。

## 10. 予報の重要な意味

- current: 実況値。AndroidではYahooから高頻度側で更新するが予報再計算には使わない。
- trend_probability: 対象市場自身の1/5/20日騰落、5/20日MA乖離をvolatility正規化して作るTrend確率。
- analog_probability: 4市場30次元の金融天気図から過去類似局面を探し、翌営業日上昇を距離加重した確率。
- up_probability: 通常 Trend 50% + Analog 50%。Analog不足時はTrendのみ。
- weather: 最終up_probabilityから分類。
- range_low / range_high: 20日volatility × 1.28を使う上下対称レンジ。
- confidence: 的中確率ではなく、Trendの方向シグナル一致度とデータ十分性。
- risk: 20日volatilityによる荒れやすさ分類。
- last_data_date: 予報計算に使った最新completed candleの市場ローカル日。
- next_session_date: その予報が対象にする次の実営業日。
